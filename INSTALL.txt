QuantSupport for 64-bit Windows Excel

Install
-------

1. Extract ALL files from this ZIP into a stable local folder.
2. In Excel, open File > Options > Add-ins.
3. Choose Excel Add-ins, click Go, then Browse.
4. Load quantsupport.xll, ExcelDna.IntelliSense64.xll and
   QuantSupport.Ribbon64.xll from that folder.
5. Restart Excel with all three add-ins enabled.
6. Enter =QS.VERSION() to check that QuantSupport loaded. Type =QS.EVALUATE(
   to see the function signature and help for the current argument.

Keep quantsupport.intellisense.xml in the same folder as quantsupport.xll. If
you rename the QuantSupport XLL, give the XML file the same base name. When you
replace the add-in, extract the new ZIP as a whole so the XML matches the XLL.

The ribbon and IntelliSense add-ins need .NET Framework 4.6.2 or later. Follow
your organization's policy for downloaded add-ins and trusted locations. Excel
for macOS and Excel in the browser cannot load these XLLs.

Load the add-ins before opening an example workbook. If the workbook was already
open, press Ctrl+Alt+F9 to rebuild its formulas and objects.

Without the IntelliSense add-in, type a function name and press Ctrl+A to open
Excel's Function Arguments dialog. Ctrl+Shift+A inserts the argument names.

Writing formulas
----------------

Create a market with QS.CONTEXT.CREATE, add data to it with the
QS.CONTEXT.ADD.* functions, and price with QS.EVALUATE. Click Setup Guide on the
ribbon for worksheet examples. The add-in does not include creation wizards.

Calculation
-----------

QuantSupport.Ribbon64.xll must be loaded for background results to reach the
worksheet. Cells show #N/A while their results are pending.

- Refresh Pricing calculates the workbook and waits for background prices and
  the cells that depend on them. It also works in Manual calculation mode.
- Reset Memory & Rebuild clears all QuantSupport objects and calculation memory
  in this Excel instance, then recalculates every open workbook. It works in
  Manual mode too. It does not change the calculation mode or edit formulas.

The add-in keeps your calculation mode and Excel's RTD throttle setting.

Using the ribbon
----------------

- Pricing Contexts and Instruments & Trades open the workbook object browser.
- Inspect Selection shows the object in the active cell.
- Select an object and click Go to cell to edit its inputs.
- To price, select an instrument or trade and click Price Selection, or use
  Pricing in the panel. Choose a context and pricer, then run PV, Cashflows,
  Fair rate (with a leg or segment number starting at 0) or Sensitivities.
- Sensitivities lists risk factors and raw derivatives per unit of each factor.
- An instrument preview uses the displayed trade date, side and instrument
  notional. A bond preview also needs a CleanPrice, DirtyPrice or ZSpread
  anchor and value. An existing trade uses its own position terms.
- Curves opens curve tables and Instruments & inputs. Click Refresh table to
  load a view, then select an instrument row to see its parameters. Select a
  pricing context to see market levels.

The browser shows the live objects of the active workbook. It updates when
objects change and Excel is ready. Browsing never recalculates the workbook.

In the browser, Valuation date is the market's reference date. Snapshot (UTC)
is the historical observation timestamp, when there is one. Neither is the time
the object was created.

Upgrading older workbooks
-------------------------

Older store constructors and aliases are not available in this version. Rebuild
those workbooks with QS.CONTEXT.CREATE, the QS.CONTEXT.ADD.* functions and
QS.EVALUATE. Evaluation does not need a PREPARE call or an input range.
